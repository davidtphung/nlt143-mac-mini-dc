# NLT143 RESEARCH: Mac mini data center designs

Interactive 3D site for Mac mini inference clusters at One Wilshire (CoreSite LA1), an El Segundo warehouse, and an Irvine office/flex IT room. Built with React, Three.js (react-three-fiber), and Vite.

Live: https://davidtphung.github.io/nlt143-mac-mini-dc/

This repo hosts the published static build. The `gh-pages` branch is the site. `site.json` points at a build tarball with its SHA-256; the workflow in `.github/workflows/publish.yml` verifies the checksum and publishes it to `gh-pages`.
